No-cost quote validation

Clone or download the three source files, then run the unsigned quote path locally. It expects HTTP 402 and does not read a wallet secret.

node buyer.mjs --quote email
node buyer.mjs --quote domain
node --test test.mjs
Real-money boundary: --pay can transfer real USDC from a buyer-controlled wallet. Do not run it unless you own the wallet, approve the live quote and intend to purchase the service. Never paste a private key into this page, GitHub, chat or a public build log. Do not blindly retry after an ambiguous paid response.

Four allowlisted routes

Email Domain Evidence

0.001 USDC / call

Format and public DNS/domain evidence for one address. Not mailbox existence or deliverability proof.

Domain & Company Evidence

0.003 USDC / call

Bounded public DNS and website context. Not corporate identity or KYB certification.

Batch Email Evidence

0.005 USDC / call

Domain evidence for 1–10 addresses. No SMTP mailbox probe.

Web Content Evidence

0.002 USDC / call

Bounded public HTTPS source evidence for RAG. No private login or paywall access.
