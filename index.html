FAQ

Is my data uploaded anywhere?No. The file is processed inside your browser only. You can go offline after loading the page and verify it yourself.
Will it work with my store’s export?It recognises common Arabic and English column names and lets you map columns manually. We have not tested every possible export template — try the free version before buying.
Are the numbers accurate?Only as accurate as what you enter. Tabby, Tamara and Apple Pay fee rates are default estimates flagged “estimate” — set them from your contract. It is not a substitute for an accountant.
Is it affiliated with Salla or Zid?No, it is an independent tool. Salla and Zid are trademarks of their owners.
Does this replace e-invoicing (ZATCA)?No. Meezan is a profit-analysis tool only; it does not issue invoices or file returns.
