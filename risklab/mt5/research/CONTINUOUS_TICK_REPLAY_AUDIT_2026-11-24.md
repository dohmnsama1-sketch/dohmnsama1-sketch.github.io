# ZALAH 2026-11-24 — continuous tick replay and realized-loss audit

## Completed research engineering
- Code `risklab/mt5/research/tick_exact_sma_replay.py` now has `replay_files([...])`, which reads each pinned historical compressed BID/ASK file in order, **without resetting** open positions, SMA and ATR history, floating equity, daily loss latch or portfolio state between weekly archive boundaries. `replay_week()` delegates to the same engine for source compatibility.
- Timestamp monotonicity is checked **across** files. Each weekly CSV header is validated and an empty input list is rejected. Single-file / split-file equivalence tests deliberately split an input **within the same M5 candle** and assert equal trade history, P/L, risk and signal counts; wrong order and malformed second headers are rejected.
- A subsequent accounting fix extends tick-marked equity drawdown to include **actual simulated realized exits**, including adverse slippage on stops and attempted risk-triggered closes. This avoids understating drawdown by looking at current quotes just before an even worse executed fill. The updated metric is still **simulated**, not independently verified broker equity.

## Independent longer-period evidence remains negative
- [Full-year research run 45299310847](https://github.com/dohmnsama1-sketch/dohmnsama1-sketch.github.io/actions/runs/45299310847) **successfully completed**, with 84,371,369 public BID/ASK source ticks, 63,275 M5 bars, and losses in all three researched strategy families at assumed 0.15 USD/oz adverse slippage per side and assumed $7 per standard lot round trip: SMA -$937.59 on 224 trades; EMA+ADX -$145.45 on 47 trades; Donchian breakout -$860.87 on 197 trades. Exploratory weekly block-resampling P/L lower bounds were negative for all three (-$2,390.20, -$632.16, -$1,710.31 respectively). None qualify for a supervised DEMO profitability approval.
- The user wants very high **daily** profit with practically zero loss, but no available independent data demonstrates this goal. Always report both **no-trade days** and loss days; use a genuinely future untouched OOS series, not re-label already-inspected periods as a holdout.

## Remaining operational blockers
1. MQL5 EA `ZALAH_RiskHeartbeat_Research_v107.mq5` source was not compiled in MetaEditor nor forward tested with Exness DEMO fills; the Python tick replay is a different research model, not the deployed MQL5 EA.
2. The independent quote source does not reproduce Exness spread, margins, swaps, liquidity, commissions, execution latency, rejection or gap behavior.
3. A 0.01 lot minimum gold volume is generally incompatible with a 0.5% ($0.25) risk cap for a $50 account; do not override the rejection to force trading.
4. Shock protections are reactive, and a scheduled news embargo only works using independently verifiable point-in-time event records. Nothing can predict all geopolitical shocks or prevent every loss.
5. Do not trade real money, authorize deposits, subscribe or increase leverage for this research task.
