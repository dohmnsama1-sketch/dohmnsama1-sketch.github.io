What this does not prove

A changed hash does not indicate a significant change or a factual error. A matching hash does not certify that the source is safe or true. This is not a vulnerability scanner, SSRF firewall, content scraper or unattended web crawling service.

Respect website terms and rate limits. Do not run arbitrary untrusted URLs, or use this tool to handle credentials. The free version covers one public page per state file.
